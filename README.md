# Advice Generator App

A responsive advice generator app built with React, TypeScript, and Tailwind CSS.

The app displays a random piece of advice and allows users to generate a new one by clicking the dice button.

## Features

- Generate random advice
- Display advice ID and text
- Responsive design for mobile and desktop
- Dice button with hover effect
- Uses the Advice Slip API
- Built with React and TypeScript
- Styled with Tailwind CSS

## Built With

- React
- TypeScript
- Tailwind CSS
- Vite
- Advice Slip API
